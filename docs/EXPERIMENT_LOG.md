# 실험 기록 (Experiment Log)

> 목적: IS 구간에서 **무엇을, 몇 번** 시도했는지 남긴다. 시도 횟수가 늘수록 "IS에서 좋아 보이는 결과"의 신뢰도는 떨어진다.
> 규칙
> 1. 실험은 **실행 전에** 이 표에 등록한다 (가설, 변경 요소 1개, 유지 조건, 판정 기준).
> 2. 실행할 때 `experiment_id`를 지정한다 (백테스트 요청의 `experiment_id` 필드). 실행 기록에 저장된다.
> 3. `tradingos trials` 로 실험·구간·설정별 실행 횟수를 확인한다.
> 4. 설정 버전은 불변이다. 값을 바꾸려면 새 버전을 만든다 (= 새 시도).
> 5. OOS는 봉인 상태다. 전략 정의와 판정 기준이 확정되고 별도 승인이 있을 때 한 번만 연다.
