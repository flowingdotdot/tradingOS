## 0. 한 줄 요약

**구현 오류는 발견되지 않았다. 실패는 정의에서 온다.** v1은 "OTE 구역 진입"이라고 부르지만 실제로는 5m MSS를 기다리느라 **구역보다 훨씬 아래에서** 진입하고(114건 중 102건이 OTE 구간 밖), 그렇게 진입한 뒤 **가격은 대부분 임펄스 고점 A를 넘어갔다**(손절 21건 중 17건). 즉 "약세 지속"이라는 전제 자체가 IS에서 자주 틀렸고, 진입 방식이 그 손실을 줄여 주지 못했다.

## 1. 22개 거래의 실패 원인 (`v1-mss-close`)

22건 중 손절 21, 목표 1. 손절 21건을 뜯어보면:

| 관찰 | 값 | 의미 |
|---|---|---|
| 손절 후 24시간 안에 **A(임펄스 고점) 돌파가 목표 도달보다 먼저** | **17 / 21** | 방향 전제가 틀렸다 (되돌림이 아니라 반전) |
| 손절 후 목표(B)에 먼저 도달 | 2 / 21 | 손절이 너무 가까웠던 경우는 소수 |
| 어느 쪽도 아님 | 2 / 21 | |
| 손절 전 최대 유리 변동(MFE), 손절폭 대비 | 중앙값 0.58R | 절반 이상은 손절폭의 절반도 못 감 |
| MFE ≥ 1R 도달 후 손절 | 6 / 21 | 목표(≥1.5R)에 못 미치고 되돌아옴 |
| 1시간(12봉) 안에 손절 | 7 / 21 | 진입 직후 역행 |
| 보유 시간 | 중앙값 27봉 (2시간 15분) | |

- 손실 크기는 전부 약 −1.00R이다 (비용 포함 수량 계산이 의도대로 동작). 즉 "한 번에 크게 잃은" 문제가 아니라 **승률 문제**다.
- 거래된 22건은 임펄스가 큰 쪽으로 치우쳐 있다 (범위 중앙값 3.14%, 전체 셋업 1.96%). 순손익비 검사가 작은 임펄스(손절폭이 좁아 비용 비중이 큰 것)를 걸러내기 때문이다.
- 두 변형이 **같은 임펄스를 거래한 것은 5건뿐**이고(mss-close만 17, fvg-retest만 17), 그 5건은 두 변형 모두 손절이었다. 변형 간 결과 차이는 "같은 기회를 다르게 진입"해서가 아니라 대부분 **다른 기회를 거래**해서 생긴 것이다.

거래별 수치는 `ict_failure_analysis.py` 출력의 trades 표, 차트는 HTML 파일 참조.

## 2. MSS 확인 지연이 손익비에 미친 영향

구역에 도달한 셋업 297개 중 조건에 맞는 5m MSS가 나온 것은 114개다. 임펄스를 B=0, A=1로 놓은 되돌림 비율로 보면:

| 지점 | 비율 (중앙값) |
|---|---|
| 진입 구역 하단 (터치 지점) | 0.62 |
| 되돌림 최고점 | 0.79 |
| **MSS 종가 = 진입 기준가** | **0.46** |
| 되돌림 고점에서 MSS 종가까지 반납한 폭 | 0.35 (p25 0.24, p75 0.43) |

- **MSS 종가가 OTE 구간(0.62) 아래인 경우: 102 / 114. 균형가(0.5) 아래: 66 / 114.** 확인을 기다리는 동안 가격이 임펄스 범위의 약 1/3을 이미 내려간다.
- 터치부터 MSS까지 중앙값 16봉(80분).

손익비 변화 (중앙값):

| 시점 / 가정 | 손익비 |
|---|---|
| 터치 시점, 손절을 A 위에 둔다면 (그 시점에 알 수 있는 값) | 1.58 |
| 구역 하단 진입 + 나중에 확정된 손절(되돌림 고점 위)을 썼다면 (사후 정보, 참고용) | 4.02 |
| **실제: MSS 종가 진입 + 되돌림 고점 위 손절** | **1.19** |
| 엔진 단계 (체결가·비용 반영) 거부된 21건 | 계획 1.70 → 순 1.24 |

손익비 부족으로 거부된 신호의 공통 특징 (전략 단계 68건):

| | 거부 (68) | 거래됨 (22) |
|---|---|---|
| MSS 종가 위치 | 0.37 | 0.60 |
| 반납 폭 | 0.40 | 0.22 |
| 손절폭 | 0.78% | 0.62% |
| 목표까지 거리 | 0.57% | 1.60% |
| 임펄스 범위 | 1.68% | 3.14% |

→ 거부된 신호는 "MSS가 늦게, 아래에서" 확정된 경우다. 반대로 **거래된 신호는 되돌림 고점 바로 아래에서 MSS가 확정된 경우**(반납 0.22)인데, 이것은 5m 내부 스윙 저점이 고점에 아주 가까웠다는 뜻이다. 즉 최소 손익비 규칙이 **"얕은 5m 구조의 작은 이탈"만 골라서 거래**하게 만든다. 이 선택 효과가 낮은 승률과 연결되어 있을 가능성이 있다 (가설이며 검증되지 않았다).

손절폭이 왕복 비용(0.14%)보다 작은 경우는 3/114, 2배보다 작은 경우는 10/114로 많지 않다. 비용은 주범이 아니라 악화 요인이다.

## 3. 4H Bias의 신호 제한 정도

| 항목 | 값 |
|---|---|
| IS 시간 비중 | 약세 26.2% · **중립 42.1%** · 강세 31.7% |
| 상태 전환 횟수 / 상태 지속 시간 중앙값 | 1,123회 / 28시간 |
| 서로 다른 15m 약세 임펄스 4,504개의 바이어스 | 약세 1,176 · 중립 1,873 · 강세 1,455 |
| 그중 유효한 OTE∩FVG 구역이 있는 것 2,274개 | 약세 612 · **중립 938** · 강세 724 |
| 4H 필터가 제거한 구역 유효 셋업 | 1,662 / 2,274 (**73%**) |

- 중립 상태에서 발생해 버려진 구역 유효 셋업이 938개로, 통과한 것(612)보다 많다.
- **인과성**: 4H 스윙은 발생 후 16시간(오른쪽 3봉 + 봉 종료) 뒤에야 인식된다. 감사에서 44개 거래 모두 4H 입력의 인식 시각이 결정 시각 이전임을 확인했다 → look-ahead 없음.
- **신선도 문제**: 바이어스는 최근 확정 고점 2개·저점 2개로 정한다. 임펄스 시점에 그 4개 중 가장 오래된 스윙의 나이는 **중앙값 83시간(3.5일), 상위 10%는 115시간 이상**이다. 15m 셋업(수 시간 규모)을 3~5일 전 구조로 걸러내는 셈이다.
- 필터를 통과한(약세) 거래도 17/21이 A를 넘는 반전으로 끝났다 → **이 정의의 4H 약세가 "약세 지속"을 잘 가려내지 못했다.** 다만 필터를 끄면 나아진다는 근거는 없다 (비교 실행을 하지 않았다).

## 5. 전략 구현 오류 여부

**코드가 명세와 다르게 동작하는 곳은 찾지 못했다.**
- 44개 거래 전부 look-ahead 감사 통과 (신호 재현, 신호 봉까지만 준 데이터로 동일 신호, 입력의 인식 시각 ≤ 결정 시각).
- 새 규칙을 끈 엔진이 이전 버전 실행을 값까지 재현, 워밍업 수렴 확인, 계측 전후 신호 동일.

**그러나 명세 자체가 통상적인 ICT 해석과 어긋나는 지점이 있다** (구현 버그가 아니라 정의 문제):

| # | v1 정의 | 통상적 해석과의 차이 | 관찰된 영향 |
|---|---|---|---|
| 1 | 구역 터치 후 5m MSS 종가를 기다려 진입 | OTE 진입은 보통 **구역 안에서** 진입하고 손절을 고점 위에 둔다. v1은 "OTE 구역"을 조건으로만 쓰고 진입은 구역 밖에서 한다 | 102/114가 구간 아래에서 진입, 손익비 중앙값 1.19 |
| 2 | B = 돌파 이후 처음 확정된 스윙 저점 | Dealing range는 **완성된** 레그의 고점·저점을 쓴다 | 51%가 돌파 직후 확정, 47%가 신저가로 폐기 |
| 3 | 신저가가 나오면 셋업 폐기 (새 BOS 이벤트가 있어야 다시 시작) | 저점이 갱신되면 범위를 **다시 잡는** 것이 자연스럽다 | 폐기 287건 |
| 4 | MSS = "직전 5m 추세가 강세였다가 약세 돌파"만 인정 | 되돌림이 5m 강세 구조 돌파를 만들지 않으면, 같은 종가 이탈이 BOS로 분류되어 트리거가 안 된다 | 터치 후 미트리거 173건 중 29건이 해당 |
| 5 | 목표 = B 하나 | 보통 그 아래 유동성(이전 저점들)까지 본다 | 손익비 상한이 낮음 |
| 6 | 4H 바이어스 = 확정 스윙 LH+LL | 3~5일 전 구조에 의존 | §3 |

참고: 터치 후 관측됐지만 Displacement가 없어 인정되지 않은 5m MSS는 21건이다.

## 6. 우선 검증할 개선 가설 (최대 3개)

> 아래는 **가설**이다. IS에서 본 뒤 세운 것이므로 IS 결과가 좋아져도 증거가 아니다. 검증은 OOS 한 번뿐이다.

### H1. 진입 모델: MSS 확인 대신 구역 안 지정가 진입 + 손절은 A 위
- **변경 요소 (1개 묶음)**: 진입 방식. 구역 터치를 기다렸다가 MSS로 진입 → OTE 기준선(0.705)∩FVG 구역에 지정가 매도, 손절은 임펄스 고점 A 위. (손절 기준은 진입 방식과 분리할 수 없다: MSS 전에는 "되돌림 고점"이 아직 없다.) 새 진입 모드 = definition 변경.
- **근거**: OTE의 경제적 논리는 "되돌림의 깊은 지점에서 유리한 가격에 진입"이다. v1은 확인을 기다리며 범위의 35%를 반납해 그 이점을 버린다. 기하학적으로 0.705 진입·A 위 손절의 손익비는 약 2.4다.
- **예상 부작용**: 확인이 없으므로 되돌림이 그대로 A를 넘는 경우 전부 손실이 된다 (v1에서 터치 후 A 돌파 122/297 = 41%). 손절폭이 넓어져 수량이 줄고, 손익비 2.4에서 손익분기 승률은 약 30%. 거래 수는 늘어난다. 지정가 미체결(관통 규칙)도 생긴다.

### H2. 임펄스 끝점: 신저가 시 범위 재설정
- **변경 요소 (1개)**: 구역 도달 전에 B 아래로 신저가가 나오면 셋업을 버리지 않고 B를 갱신해 OTE·구역을 다시 계산한다 (A는 유지). 진입·손절·바이어스 규칙은 v1 그대로.
- **근거**: Dealing range는 완성된 레그를 기준으로 해야 한다. v1은 절반의 경우 하락 초입의 잔물결을 끝점으로 잡고, 47%가 0.8시간 안에 무효가 된다. 강하게 연장되는 임펄스야말로 "약세 지속" 가설에 가장 부합하는 사례인데 v1은 그것을 버린다.
- **예상 부작용**: 범위가 커지면 구역이 더 멀어져 도달률이 낮아질 수 있다. FVG 선택 규칙이 복잡해진다 (연장 구간의 FVG 포함 여부). 셋업 수명이 길어져 "활성 셋업 1개" 규칙과 충돌이 늘어난다. 진입 방식이 v1 그대로면 §2의 문제는 남는다.

### H3. 4H 바이어스 정의: 마지막 구조 돌파 방향 (`bias.mode: last_break`)
- **변경 요소 (1개, 기존 파라미터)**: `swing_sequence`(LH+LL) → `last_break`. 코드 변경 없이 새 설정 버전으로 가능.
- **근거**: 현재 바이어스는 3~5일 전 스윙에 의존하고 42%의 시간이 중립이다. 통과한 거래도 81%가 반전으로 끝나 방향 필터로서 변별력이 의심된다. 마지막 구조 돌파는 더 최근 정보를 쓰고 중립 상태가 거의 없다.
- **예상 부작용**: 전환이 잦아져 횡보장에서 휩쓸릴 수 있다. 약세 판정 시간이 늘어 거래 수가 늘지만 질이 나아진다는 보장은 없다. 4H 한 번의 종가 돌파에 민감해진다.

### 이번에 제외한 후보 (기록용)
MSS 분류 완화(§5-4, 29건), Displacement 강화(§4), 목표가 확장(§5-5), 최소 임펄스 크기. 한 번에 세 개까지만 다루기 위해 보류했다. 영향 규모가 H1~H3보다 작거나, 승패 비교 표본이 없어 방향을 정할 근거가 약하다.
