### 1.1 데이터 품질 주의 사항 (검사로 발견)
1. **"결측 0"은 거래소 장애가 없었다는 뜻이 아니다.** OKX는 장애 구간을 거래량 0의 평평한 캔들로 채운다. 5m에서 거래량 0인 봉 367개(0.05%), 30분 이상 연속 구간 11개(합계 224봉). 가장 긴 것은 **2022-12-18 08:40부터 122봉(10시간 10분)**. 모두 2023년 이전이다 (2024년 이후 0개).
2. **5m로 만든 상위 봉과 OKX 원본의 차이**: 15m 242,183개 중 40개(0.017%), 4H 15,136개 중 10개(0.066%). 대부분 시가 차이, 중앙값 0.5bp, 최대 69bp (2021-05-28 18:15~18:30: 원본 15m 거래량이 5m 합계의 5배 → 5m 쪽에 누락된 체결이 있음). 전부 2023년 이전.
3. 전략은 상위 봉을 5m에서 직접 만들어 쓰므로 내부적으로는 일관되지만, 위 구간에서는 5m 자체가 불완전할 수 있다.
4. **펀딩 요율**: OKX `funding-rate-history`는 **최근 94일(2026-08-10 이후, 282건)만 제공**한다. 그 이전 6.6년은 실제 요율이 없다. 실측 평균 0.0058%/8h, 음수 비율 7.8%. 현재 엔진 가정은 0.01%/8h를 방향과 무관하게 비용으로 차감 (실측 평균보다 보수적).

→ 결정 필요 (§5-A): 거래량 0 연속 구간을 "결측"으로 취급할지.

## 2. 구간 분할 (제안)

이미 관찰한 구간은 처음 수집한 5m 데이터 전체(2026-05-14 이후)로 잡는다. 150일 백테스트뿐 아니라 170일·180일 실행, 차트 분석, Inspector 집계가 모두 이 범위에서 이뤄졌기 때문이다.

| 구간 | 기간 (UTC, 끝은 미포함) | 일수 | 비율 | 용도 |
|---|---|---|---|---|
| 워밍업 전용 | 2019-12-16 → 2020-01-01 | 15 | 0.6% | 상장 직후. 지표 워밍업에만 사용, 거래 없음 |
| **IS (연구)** | 2020-01-01 → 2024-10-01 | 1,735 | 68.8% | 구현 검증, 거래 빈도, 체결 모델, 정의 비교 |
| **OOS (봉인)** | 2024-10-01 → 2026-05-14 | 590 | 23.4% | 정의 확정 후 **한 번** 실행 |
| 기존 관찰 | 2026-05-14 → 현재 | 182+ | 7.2% | 이미 본 구간. 독립 검증에 쓰지 않음 (회귀 확인용) |

- 경계에서의 처리: OOS 실행의 워밍업(10일)은 IS 끝부분 가격을 지표 계산에만 쓴다. IS 실행은 경계에서 보유 포지션을 강제 청산한다.
- IS에는 서로 다른 국면이 들어 있다 (2020-03 급락, 2021 상승·고점, 2022 하락, 2023 횡보·회복, 2024 상승). OOS는 2024-10 이후.
- 제가 오늘 전체 기간에 대해 본 것은 데이터 품질 통계(거래량 0 봉, 최대 변동 봉, 타임프레임 불일치)뿐이며, OOS 구간의 전략 신호·성과는 보지 않았다.

### 2.1 봉인 방식 (승인 후 구현)
`backend/config/research_split.yaml`에 경계와 `oos_sealed: true`를 기록하고, 백테스트·Inspector·연구 차트 API와 CLI가 **봉인된 OOS와 겹치는 기간 요청을 거부**하도록 한다. 봉인 해제는 설정 파일 변경(커밋 기록이 남음) + 확정된 설정 버전 지정으로만 가능하다. 해제 실행은 실행 기록에 `oos_unsealed_run`으로 표시한다.

## 3. 승인 후 작업 순서

| 단계 | 내용 | 사용 구간 |
|---|---|---|
| 1 | OOS 봉인 가드 구현 + 테스트 | — |
| 2 | **비용 포함 수량 계산**: `수량 = 위험 예산 / (손절폭 + 진입가×(진입 수수료+슬리피지) + 손절가×(청산 수수료+슬리피지))`, 계약 단위(0.0001 BTC) 내림. Risk Engine에 구현 (실거래 경로와 공유) | 합성 테스트 |
| 3 | **체결가 기준 최소 손익비**: 주문 직전 예상 체결가(시장가: 다음 시가±슬리피지, 지정가: 지정가)로 재검사, 미달 시 거부·기록 | 합성 테스트 |
| 4 | **지정가 체결 모델**: 유효 기간, 미체결 중 무효화 조건(목표 선도달, 손절가 도달, 만료) 시 취소. 체결 후에는 취소 불가 → 손절/목표 관리. 같은 5m 봉에서 체결·손절·익절 순서가 불분명하면 보수적 가정(체결 봉에서 손절 가능하면 손절, 익절은 다음 봉부터 인정)을 적용하고 거래에 표시 | 합성 테스트 |
| 5 | 엔진 0.3.0 회귀: 기존 관찰 구간에서 변경 전후 차이를 항목별로 설명 | 기존 관찰 |
| 6 | **IS 실행**: 실제 거래 수 확인(60~70회는 추정일 뿐), Inspector funnel, 전 거래 look-ahead 감사, 연도별 빈도 | IS |
| 7 | IS 결과 보고 → 정의 확정 여부 결정 | — |
| 8 | (승인 시) OOS 1회 실행 | OOS |

- 2~4는 결과를 바꾸는 엔진·리스크 변경이다. 전략 파라미터는 건드리지 않는다. 3의 "전략 수준 규칙 vs 엔진 수준 규칙" 배치는 §5-B.
- 과거 펀딩: 실제 요율이 있는 94일은 기존 관찰 구간 안에만 있다. IS/OOS는 전 구간 가정값이며, 실행 기록에 `funding: assumed`로 표시한다.

## 4. 판단 기준 (결과를 보기 전에 고정)
- 표본: IS 거래 수가 **30건 미만이면 성과 지표로 결론을 내리지 않는다** (빈도·구현 검증만 보고).
- 보고 항목: 거래 수, 연도별 분포, 기대값(R)과 그 불확실성(부트스트랩 신뢰구간), 비용 비중, 최대 연속 손실, Inspector 단계별 통과율.
- IS에서 설정을 비교한 횟수(시도 수)를 기록한다.
